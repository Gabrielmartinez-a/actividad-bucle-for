Numero Mayor de Tres

Este programa en C++ determina cual de tres numeros ingresados por el usuario es el mayor.

**Autor:** Gabriel Burgos Martinez
**Matricula:** 2026-1768
**Lenguaje:** C++

### Descripcion
El programa solicita 3 numeros y utiliza estructuras condicionales `if - else if` para comparar y mostrar el numero mayor.

### Como ejecutar
1. Abrir el archivo `numero-mayor-de-tres.cpp` en Visual Studio
2. Compilar con Ctrl + F5
3. Ingresar los 3 numeros
