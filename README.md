### Descripción breve del programa
Programa en C++ que solicita un número entero y muestra su tabla de multiplicar del 1 al 12. El programa forma parte de las actividades propuestas del tema de estructuras repetitivas.

### Datos de entrada
- Un número entero para generar su tabla de multiplicar.

### Datos que procesa
- Realiza la multiplicación del número ingresado por cada uno de los valores comprendidos del 1 al 12 mediante un contador.
- Almacena y muestra el resultado de cada multiplicación.

### Datos de Salida
- La tabla de multiplicar del número ingresado, desde el 1 hasta el 12, en el formato "N x i = resultado".


### Una descripción breve explicando por qué usó x estructura y que función hace
Usé la estructura `for` porque es una estructura repetitiva que se utiliza cuando se conoce el número exacto de veces que se debe repetir un bloque de código. En este caso se debe repetir 12 veces para la tabla. La función del `for` es inicializar una variable de control (i=1), comprobar una condición (i<=12) y actualizar la variable (i++) en cada iteración hasta completar el ciclo.
